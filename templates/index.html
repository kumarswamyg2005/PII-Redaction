That number is where precision comes from; a tool that redacts everything scores perfect recall and destroys the document.

Consistent Caching
Ensures the exact same person name maps to the same fake identity across all 100+ pages.
Reads the Glossary Before Deciding
The document's own “Definitions and Abbreviations” tables are parsed at run time — every one of them, keyed on row shape rather than on a named table — so its vocabulary is known before any redaction happens. On the supplied prospectus that is 599 terms.
Definitions Survive, Parties Do Not
An abbreviation's expansion is vocabulary and stays — whole and in part, so a phrase lifted from the middle of one is safe too: “PM-KUSUM — Pradhan Mantri Kisan Urja Suraksha evam Utthaan Mahabhiyan Yojana”. Two guards keep that narrow. “SBI — State Bank of India” is an acronym row, and the bank is still redacted. And the glossary is where the parties are defined too, so only acronym rows qualify — which is what keeps every promoter redactable.
Learns the Document's Own Vocabulary
Indexes every phrase the file writes with a lower-case first letter, because a proper noun is capitalised wherever it appears. That is how “Delay in or inability of the vendors…” is known not to be a person's name — the same document says “any delay in placing the orders”. Derived per document, not a fixed stop-word list.
Headings Are Structure
A section heading is recognised by repetition — a contents entry names a section that carries the same words as its title — or by a trailing page number, so “TABLE OF CONTENTS” is never mistaken for a company and the contents page survives intact.
Contextual DOB
Only redacts dates associated with DOB keywords, preserving filing and FY dates.
Linked Website Anonymization
Redacts private company URLs and domains using a consistent fake domain derived from the same company identity.
In-Place Rewriting
Edits the original file in place: fonts, tables, images, headers and page breaks are preserved exactly, with only PII values changed.
Institutional Domain Policy
Leaves regulator and exchange domains (sebi.gov.in, bseindia.com, nseindia.com) intact, while redacting every private counterparty domain — banks, brokers, registrars and advisers alike.
